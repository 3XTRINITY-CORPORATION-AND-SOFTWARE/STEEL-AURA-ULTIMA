# Media bank I/O

## Audio
- Upload/download: **WAV** (max quality preferred), **MP3**
- Bound to memory bank id

## Video
- Upload/download: **MP4**
- Resolutions: **480p → 4K**
- Frame rates: **25–60 fps**
- Smaller AURA emits pattern-sync sidecar for Ultima (JSON/binary journal, 1:1 with audio timeline)

## Acceptance
Round-trip upload → bank → download preserves format; video stays in declared fps/res class.
